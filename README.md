# Mapa de Atuação Programático

Mapa das organizações do Ecossistema de Impacto da Fundação Lemann, com consulta
a programas e estratégias, filtros e atualização de dados por contas autorizadas.

O projeto inclui login Google, integração de sessão com a agenda do Ecossistema
e saída conjunta dos dois sites.

Este pacote contém o código-fonte, os recursos visuais e os testes do mapa.
Não inclui credenciais, sessões nem backup dos dados de produção.
