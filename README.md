# Mapa de Atuação Programático

Mapa dos programas e das estratégias de atuação das organizações do Ecossistema
de Impacto da Fundação Lemann.

A plataforma permite consultar os programas, aplicar filtros e explorar os mapas
de atuação por estratégia.

## Atualização dos dados

A fonte de atualização é uma planilha do Google Sheets com as abas Programas
e Além do mapa programático. Os nomes das abas e os cabeçalhos devem ser mantidos.

1. Edite os dados na planilha oficial.
2. No site, uma pessoa administradora clica em Atualizar do Google Sheets.
3. Confira a prévia no mapa e clique em Publicar atualização.

A leitura não altera os dados publicados. Falhas de leitura, preenchimento ou
gravação preservam a última versão publicada. Alterações concorrentes são
verificadas antes da gravação. Não é necessário baixar ou enviar arquivos.

O repositório contém o código-fonte, os recursos visuais e os testes do mapa.
Não inclui credenciais, sessões nem cópia dos dados de produção.
