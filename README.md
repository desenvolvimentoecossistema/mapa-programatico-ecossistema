# Mapa de Atuação Programático

Código para repositório GitHub e implantação pela TI. Leia primeiro
[INSTRUCOES-PARA-TI.txt](INSTRUCOES-PARA-TI.txt), incluído nos dois projetos.

Esta entrega não define provedor de hospedagem. A compatibilidade do servidor,
do banco e do armazenamento deve ser verificada antes da publicação. O projeto
exige backend; publicar somente os arquivos estáticos não preserva o funcionamento.

O guia contém as variáveis, URIs Google, integração entre origens, migração dos
dados, comandos de build/teste e roteiro de aceitação. `.env.example` tem apenas
valores de exemplo; segredos devem ficar no ambiente protegido do servidor.

Não há backup da produção ou sessões neste pacote. O identificador da hospedagem
atual foi removido do manifesto para não vincular a cópia ao site existente.

Fonte da aplicação: commit `01707ea4adf937649335472cbc2bd517530fed2b`. Os acréscimos desta entrega são documentação,
modelos sem segredos e, na agenda, a estrutura SQL consolidada sem registros.

Entrega enxuta: componentes sem uso e arquivos redundantes foram retirados.
O bundle do mapa é gerado pelo build e não precisa ficar versionado.
