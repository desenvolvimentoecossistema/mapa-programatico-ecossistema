# Mapa de Atuação Programático

Mapa das organizações do Ecossistema de Impacto da Fundação Lemann, com consulta
a programas e estratégias, filtros e atualização de dados por contas autorizadas.

Inclui login Google, integração de sessão com a agenda do Ecossistema e saída
conjunta dos dois sites.

[Baixar o pacote completo do mapa](mapa-programatico-github.zip)

O código-fonte completo está no ZIP. Credenciais, sessões e backup dos dados de
produção não estão incluídos.
